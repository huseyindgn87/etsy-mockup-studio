Several things it deliberately refuses out loud rather than guess at, because Etsy's Open API v3 spec documents no semantics for them — emptying a listing's tag or material list, moving a listing to "no section", clearing a category attribute, clearing an item weight/size, and emptying a variation grid (removing a property's last option). After a successful Save to Etsy in the editor, rendered/own tiles stay in the grid, so saving again uploads them again (same as the old "Add").
